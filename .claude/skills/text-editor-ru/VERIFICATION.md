# Проверка выпуска 1.0.0

Дата: 2026-10-14.

## Выполнено

- Локально выполнена команда `python -m unittest discover -s tests -v`.
- 24 теста прошли: 20 проверяют лексический помощник, 4 — структуру пакета.
- Проверены изменённые числа, повтор числа, знак, единица, граница с защитой,
  отрицание с защитой, код, таблицы, URL, цитатный маркер, ошибки входа и
  отсутствие записи в исходные файлы. Отдельный тест показывает, что
  перестановка ролей может пройти лексическую проверку, не подтверждая смысл.
- Проверены относительные ссылки, заголовок SKILL.md, версия и структура
  18 сценариев поведения. Основная инструкция: 168 строк.
- Среда первого запуска: Python 3.13.5, Linux.

## Не заявляется выполненным

- Полный модельный прогон 18 сценариев в пользовательском агенте.
- Установка и активация навыка в конкретной среде.
- Экспериментальное сравнение качества с исходными навыками.
- Доказательство смысловой эквивалентности автоматическим скриптом.
- Проверка фактов реальных документов компании: они не использовались.

Структурный тест пакета — собственная проверка, а не сертификация Agent Skills.
Инструкции по поведенческой приёмке: [eval/README.md](eval/README.md).
