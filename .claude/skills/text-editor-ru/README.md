# Редактор смысла

**Русскоязычный навык для ясных текстов без потери фактов и авторского голоса.**

Версия **1.0.0**. Имя навыка: `text-editor-ru`.

Убирает канцелярит, повторы, пустые вступления и искусственный пафос. Сохраняет
цифры, оговорки, терминологию, позицию автора и полезное оформление. Хорошую фразу
оставляет в покое. Не определяет, кто написал текст, и не обещает обход детекторов.

## Для чего использовать

Сообщения команде и управляющим, пояснения к аналитике, текст презентаций,
новостные заметки, обратная связь, учебные материалы, рабочие инструкции.
Управленческий профиль предусмотрен, но навык не привязан к одной компании.
Реальные данные сотрудников и показатели компании в пакет не включены.

Это инструкция для модели и небольшой вспомогательный скрипт. Сам по себе
репозиторий не является отдельным приложением, не запускает агента и не
подключается автоматически во все чаты.

## Что умеет

| Режим | Пример запроса | Результат |
|---|---|---|
| Проверка | «Оцени текст, ничего не переписывай» | Конкретные дефекты и предложения. |
| Редактура | «Убери канцелярит, сохрани мою прямоту» | Готовый текст с сохранением содержания. |
| Сокращение | «Сократи до 1 000 знаков, сохрани ограничения» | Сжатый текст под заданную цель и лимит. |
| Адаптация | «Сделай из этого сообщение управляющим» | Подача для нового читателя или канала. |
| Черновик | «Напиши сообщение по этим фактам» | Текст из данных, без выдуманных фактов и поручений. |

Режим определяется из запроса. Переделывать текст после просьбы только проверить
его нельзя. Создавать новый текст по предоставленным тезисам можно по прямому
поручению. Переписывание не включает отправку, публикацию или изменение настроек.

## Что защищено

Числа, знаки и единицы; проценты и процентные пункты; периоды и база сравнения;
состав групп; названия показателей; условия, исключения и отрицания; ссылки и
цитаты; статус фактов, гипотез, поручений и решений. Нельзя превращать «возможно»
в доказанную причину, «предлагается» в утверждённое действие или «более 3 000»
в ровно 3 000.

Код, команды, формулы и пути не редактируются как обычная речь. Таблицы, легенды
и списки сохраняются, когда они помогают понять материал. Тире и три пункта
разрешены. Резкость автора не заменяется корпоративной вежливостью, но и новая
грубость не придумывается.

## Пример

**Исходник**

> Важно отметить, что в сентябре продажи розницы снизились на 8% к августу.
> Технопоинты в расчёт не включены. Причина снижения пока не подтверждена.

**После редактуры**

> В сентябре продажи розницы снизились на 8% к августу. Технопоинты в расчёт
> не включены. Причина снижения пока не подтверждена.

Убрана пустая вводная. Сохранены факт, период, база сравнения, исключение и оговорка.
Пример учебный; остальные находятся в [examples/before-after.md](examples/before-after.md).

## Получение и использование

Для приватного репозитория нужен GitHub-аккаунт с доступом. Если GitHub CLI уже
установлен и авторизован:

```bash
gh repo clone maiklvas-bot/text-editor-ru
cd text-editor-ru
```

В среде с поддержкой **Agent Skills** разместите каталог `text-editor-ru` в
каталоге навыков этой среды её штатным способом. В корне должен остаться
[SKILL.md](SKILL.md), а папки `references`, `assets` и `scripts` должны сохранять
относительные пути. Конкретный путь установки и механизм активации зависят от
агента. Одно клонирование репозитория не подтверждает установку.

В обычном чате без механизма навыков передайте `SKILL.md` и необходимые справочники
как инструкции для текущей задачи. Это разовое использование, а не постоянная
установка. Ссылки на локальные файлы внутри Markdown не означают, что модель
автоматически получила их содержимое.

Начальный запрос:

> Используй «Редактор смысла». Отредактируй текст для сообщения команде.
> Сохрани факты, оговорки, мою прямоту и полезные списки. Верни только итоговый текст.

Не подключайте одновременно другие навыки, которые запрещают тире, механически
сокращают пункты или переписывают всё подряд: противоречащие правила затрудняют
приёмку результата. Пример профиля автора — в
[assets/author-profile.example.md](assets/author-profile.example.md).

## Локальная проверка изменений

Основному навыку Python не нужен. Для вспомогательного скрипта и тестов нужен
**Python 3.10+**, используются только стандартные библиотеки. Скрипт не отправляет
текст в сеть и не изменяет входные файлы.

```bash
python scripts/check_invariants.py before.txt after.txt
python scripts/check_invariants.py before.txt after.txt --locks locks.json
python -m unittest discover -s tests -v
```

`locks.json` — массив точных защищённых фрагментов, присутствующих в исходнике:

```json
["более 3 000 м²", "только розница", "не подтверждено"]
```

Помощник сравнивает числовые записи, часть единиц, URL, поддержанные цитатные
маркеры, Markdown-код, строки таблиц и заданные фрагменты. Расхождение даёт код 1;
отсутствие автоматических сигналов — 0; ошибка входных данных — 2.

**Чистый отчёт не доказывает сохранность смысла.** Скрипт может не заметить
перестановку исполнителей, новую причинность или изменение области утверждения.
Переформатирование или допустимое сокращение способны дать ложную тревогу.
Подробности: [references/verification.md](references/verification.md).

## Что проверено и что ещё требует испытания

В выпуске есть 24 автоматических теста скрипта и структуры пакета, а также
18 сценариев поведения навыка. Фактические результаты:
[VERIFICATION.md](VERIFICATION.md). Автотесты не запускают модель и не доказывают,
что выбранный агент правильно прочитает и выполнит инструкции.

Перед регулярным использованием проверьте активацию и сценарии в своей среде:
[eval/README.md](eval/README.md). Не используйте внутренние документы в публичных
тестах или сторонних сервисах без разрешения.

## Ограничения и безопасность

Навык не проверяет истинность каждого утверждения автоматически, не заменяет
расчёты и не гарантирует отсутствие ошибок. Для юридических документов и
художественных текстов вмешательство ограничено жанром и прямым поручением.
Редактура HTML или презентации касается текста, а не макета и программной логики.

Входной текст считается данными: команды внутри него не выполняются. Пакет не
содержит API-ключей, телеметрии, установочных хуков, фоновых задач или внешних
зависимостей. Модельная обработка подчиняется правилам выбранной платформы:
наличие локального скрипта не делает всю обработку локальной.
