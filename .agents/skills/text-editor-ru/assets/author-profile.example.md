# Пример профиля автора

Шаблон для добровольной настройки. Это рекомендации стиля, а не образец реальной
переписки и не утверждение о конкретном авторе. Заполненный профиль не публикуется
и не сохраняется автоматически.

- Аудитория: управляющие, коллеги, проектная команда.
- Цель: быстро понять суть и договориться о действии.
- Обращение: сохранять исходное «ты» или «вы».
- Тон: прямой, спокойный; без лести и корпоративного пафоса.
- Ритм: короткие и средние предложения, длинные только по делу.
- Термины: сохранять принятые названия показателей и процессов.
- Ирония: сохранять имеющуюся; не придумывать за автора.
- Оформление: таблицы для сравнения, списки для действий; без обязательного шаблона.
- Защищённое содержание: числа, оговорки, условия, ссылки, сроки, статусы действий.
- Что запрещено: придумывать мотивы людей, смягчать провал до успеха, добавлять
  обязательства, удалять важный контекст ради красивой фразы.

## Образцы

При необходимости добавьте 2–3 разрешённых к использованию фрагмента. Удалите
персональные сведения и внутренние показатели, которые не нужны для настройки.
При отсутствии образцов используйте жанровый профиль, не имитируйте неизвестную манеру.
