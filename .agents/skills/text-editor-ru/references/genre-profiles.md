# Жанровые профили

Профиль задаёт подачу, не даёт разрешения выдумывать содержание. Все схемы ниже
применяются только там, где соответствующие сведения есть в исходнике или
пользователь поручил разработать предложение.

| Жанр | Предпочтительная подача | Что особенно защищать |
|---|---|---|
| Сообщение команде | Суть и нужное действие; контекст только необходимый | Срок, исполнитель, тон обращения, добровольность или обязательность. |
| Обратная связь сотруднику | Наблюдаемое поведение, последствия, договорённость | Не подменять факт оценкой личности; не добавлять мотивы человеку. |
| Аналитическое пояснение | Наблюдение, значение для решения, ограничение | Период, единицы, состав групп, база сравнения; гипотеза не становится причиной. |
| Новостная заметка | Событие и дата; значение для аудитории | Источник, дата события и дата публикации, факт и мнение. |
| Учебный материал | Объяснение, пример, способ применения | Условия применимости; пример не выдавать за установленный факт. |
| Инструкция | Понятная последовательность действий | Порядок, условия перехода, запреты, исключения, критерий окончания. |
| Презентация | Короткий заголовок и один ясный тезис блока | Числа, единицы, легенды, структура таблиц, данные графиков и компоновка. |
| Личное письмо или пост | Манера автора и живые конкретные детали | Не добавлять переживания, опыт, позицию или шутки от имени автора. |
| Договор, нормативный текст | Проверка и точечные предложения | Термины, определения, модальность, условия и обязательства. |
| Академический текст | Точный тезис, метод, результат, ограничения | Терминология, оговорки, цитирование, степень доказанности. |
| Художественная проза, поэзия | Только порученный слой | Авторский синтаксис, ритм, повтор, неоднозначность и образность. |

## Рабочий профиль для руководителя розницы

Включай при соответствующей аудитории. Пиши прямо и без назидательного пафоса.
Не превращай поручение в корпоративный лозунг. Различай проблему процесса,
результат магазина и оценку человека. Плохой показатель не доказывает плохую
мотивацию сотрудника. Термины компании сохраняй; новые сокращения объясняй.

Структура «что происходит → что это значит → что делаем → как проверяем» полезна
для решения, но не обязательна в каждом абзаце. Если причины, действия или критерии
не даны, не дописывай их в режиме редактуры. В режиме разработки предложений
обозначай их как предложения.

Данные другой компании, старого отчёта или другого проекта сюда не переносятся.
Реальные кадровые сведения и рабочие показатели не нужны для настройки навыка.
