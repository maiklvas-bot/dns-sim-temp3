# Изменения

## 1.0.0 — 2026-10-14

Первый выпуск. Пять режимов текстовой работы; защита фактов и авторского голоса;
жанровые профили; сохранение полезной структуры; отдельная проверка источников;
локальный помощник лексической сверки; тесты и сценарии поведения.

Отказ от механических запретов на тире и три пункта, обязательного переписывания
каждого текста, определения авторства и обещаний смысловой гарантии по результатам
программного сравнения. Настоящие данные компании в пакет не включены.
