# Дорожная карта SimCenter (DNS HR Ural)

Отдельный инструмент планирования. К коду симуляции («Космонавт», ЗРД) он не подключён: не импортирует его, не читает его базу и не меняется вместе с ним. Репозиторий используется как место хранения.

## Что здесь

| Файл | Назначение |
|---|---|
| `template.html` | Исходник страницы: диаграмма Ганта, исполнители, канбан, история и события, форма. Метка `__LOGO__` подставляется при сборке |
| `build.py` | Собирает `page.html` и автономный `dorozhnaya-karta-offline.html` |
| `dorozhnaya-karta-offline.html` | Один файл, открывается двойным щелчком, без сети. Данные хранятся в браузере; кнопка «Скачать копию (JSON)» делает резервную копию |
| `state.json` | Стартовые данные: 17 задач, 10 событий, 3 вехи (снимок на 05.11.2026) |
| `mkxlsx.py` | Строит `Дорожная карта SimCenter.xlsx` из `state.json` (диаграмма Ганта по неделям формулами, списки, условное форматирование) |
| `mark.b64` | Метка DNS для шапки |

## Как пользоваться

```bash
cd docs/project/roadmap-tool
python3 build.py            # пересобрать страницу и офлайн-файл
pip install openpyxl && python3 mkxlsx.py   # пересобрать таблицу
```

Правки вносятся в `template.html`, затем `build.py`. Готовые файлы пересобирать, а не править руками.

## Как устроена карта

- Задача на стикере считается полной, когда заполнены 6 полей: название, направление, кто отвечает, срок, результат, основание. Неполные задачи лежат в колонке «Черновики» и не попадают на диаграмму Ганта.
- Правка в канбане, диаграмме или форме меняет одну и ту же задачу; остальные вкладки перестраиваются.
- Любое изменение задачи пишет событие в историю с причиной; у задач есть ссылки на документы и рецензии, из которых видно, откуда взято решение.
- Импорт из Miro: строки `название; кто; начало; конец` (разделитель табуляция, `;` или `|`) превращаются в стикеры.
- Сроки задач `t1`–`t10` предварительные (поле «Срок предварительный»), это допущение, а не решение команды.

## Ограничения

- Офлайн-версия хранит данные только в браузере, на другой компьютер они сами не переходят: переносить через JSON.
- Шрифты бренда в офлайне заменяются системными.
- Настоящего логотипа HR Ural в материалах нет: в шапке метка DNS и подпись «HR Ural».
