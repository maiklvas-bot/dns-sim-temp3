# Предложения по правилам проекта

Сюда управляющий записывает по заключению `auditor` (у самого `auditor` права записи нет), где правила проекта не покрыли ситуацию, спорят между собой или потребовали лишнего. Правила и реестр (`docs/project/routes.json`, профили, `docs/project/claude-headquarters.md`, `CLAUDE.md`) по этим записям сами не меняются: решает владелец. Один случай — это наблюдение; правку предлагают при повторе или явном дефекте.

Статусы: предложено, принято, отклонено, наблюдение. Решение владельца записывается в строку с датой.

| Дата | Где (файл, раздел) | Что случилось (с доказательством) | Предлагаемая правка | Статус |
|---|---|---|---|---|
