## Логика опроса

Не переспрашиваем веса/приоритеты — они уже посчитаны из v2. Здесь только **сбор поведенческих
якорей**: по каждой из 12 компетенций — один вопрос про слабое проявление, один про сильное.
Порядок — **по убыванию веса** (раздел 2 критериев), чтобы при усталости респондента самое важное
было отвечено первым.

⚠️ **Честно про длину:** 12 компетенций × 2 вопроса = 24 открытых вопроса + профиль ≈ **25–35 минут**.
Это заметно длиннее v2. Предлагаю пометить последние 2 (self_awareness, staff_roles — вес 0.6 каждая,
статистически на грани значимости) как **необязательные**, чтобы не терять данные по важному из-за
усталости на второстепенном. Можешь оставить обязательными все — решаешь ты.
