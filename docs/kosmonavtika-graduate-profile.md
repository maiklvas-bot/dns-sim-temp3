# Профиль выпускника «Космонавтики» (целевой профиль компетенций)

> **Канон-референс.** Источник: `Профиль КОСМО_выходная оценка_2026.pdf` (предоставлен пользователем
> 2026-07-12). Это профиль должности, которому должен соответствовать сотрудник, **завершивший курс
> «Космонавтика»**. Целевая роль — **ЗУМ** (заместитель управляющего магазином): индикатор №13
> прямо про «готовность выполнять обязанности ЗУМ».

## Контекст (что такое Космонавтика и зачем симуляция)

- **Космонавтика** — обучающий **курс**: группа претендентов проходит отбор, затем ~2 месяца
  обучения начальным управленческим навыкам с тренером (домашние задания + очные + онлайн-встречи).
  На выпуске — **выходной ассессмент** (беседа с комиссией) против этого профиля.
- **Разрыв, который закрывает симуляция (бизнес-проблема, гейт 3.1):** между моментом выпуска
  (человек приходит на подразделение «только со сырыми знаниями») и моментом, когда он выдаёт
  хорошие **практические** решения. Симуляция в **безопасной цифровой среде** даёт применить навыки —
  превратить «знает/называет» в «делает».
- **Второй слой (поздние итерации):** симуляция как элемент **поддержки управленческого решения** —
  сравнение претендентов на должность по усреднённым результатам прохождения.

## Ключевое наблюдение для пересборки

Индикаторы профиля сформулированы преимущественно как **вербальные** («Называет…», «Говорит…»,
«Объясняет…») — их проверяет комиссия в беседе. Симуляция должна конвертировать каждый такой
индикатор в **наблюдаемое действие** под давлением операционки (перенос знаний в практику,
Киркпатрик ур. 3). Это прямая связь с §8a-антигеймингом: сигнал — по уместности действия, а не по
красоте формулировки.

| 4 | Задачи сотрудников магазина | называет цели и задачи УМ и ЗУМ; основные обязанности ПК (УСМ), Кладовщика, Кассира |
| 5 | Идеология Компании | называет Миссию и Предназначение; решения соотносятся с ними |

## Как это связано с движком Космонавта

Компетенции у Космонавта — **данные** (`CompetencyDefinition{id,name,description,category}` в
`shared/simulation-content.ts`, категории basic/advanced/leadership; баллы — `competency_scores` на
вариант ответа кейса, `shared/simulation-scoring.ts`). При пересборке эти 14 — целевой набор,
который контент кейсов должен покрывать через наблюдаемые действия, а не через пересказ.
