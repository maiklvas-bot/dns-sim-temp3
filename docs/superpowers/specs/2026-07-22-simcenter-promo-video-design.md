# Промо-ролик DNS SimCenter — дизайн

## Цель
Внутренний мотивационный ролик для сотрудников DNS: рассказать, что такое SimCenter
(бизнес-симуляция оценки управленческой готовности), как проходит live-сессия, и
замотивировать участвовать ради собственного развития. Показ — внутренний портал / рассылка HR.

## Формат
- Длительность: ~2:30 (150 секунд), 30 fps, 4500 кадров, 1920×1080.
- Без закадрового голоса: текст на экране + фоновая музыка.
- Стиль: смешанный — деловой каркас DNS (см. токены ниже) + вставки реальных экранов приложения.
- Структура повествования: гибрид «объяснение по шагам» + обращение к зрителю на «вы»
  (проблема → решение → как работает → выгода → CTA, поданное лично, не через вымышленного героя).

## Дизайн-токены
Источник истины — `client/src/styles/dns-theme.ts` (копируется в
`video/simcenter-promo/src/theme.ts`, не переизобретается):
- DNS Orange `#F04E23` (primary), `#FF6B35` (light), `#D84315` (dark)
- Фон: Navy `#0F1923` (bgDark), `#1A2634` (bgCard), `#243447` (bgElevated)
- Текст: `#FFFFFF` / `#94A3B8` / `#64748B`
- Шрифт: Inter (sans), JetBrains Mono (для кодов доступа/технических вставок)
- Радиусы, тени, градиенты — как в `DNS_BORDERS`, `DNS_SHADOWS`, `DNS_GRADIENTS`

## Архитектура
Новый изолированный Remotion-проект, не влияющий на зависимости основного приложения:

```
video/simcenter-promo/
├── package.json          — свои зависимости (remotion, react, @remotion/cli)
├── src/
│   ├── Root.tsx           — регистрация композиции SimCenterPromo (1920×1080, 30fps, 4500f)
│   ├── SimCenterPromo.tsx — таймлайн, <Sequence> на каждую сцену
│   ├── scenes/            — Title, Problem, Solution, HowItWorks1, HowItWorks2,
│   │                        HowItWorks3, PdfReport, GrowthPitch, Cta
│   └── theme.ts           — токены из dns-theme.ts
├── public/
│   ├── screenshots/       — PNG реальных экранов приложения
│   └── audio/bg-music.wav — сгенерированная амбиент-подложка
```

Рендер: `npx remotion render` → `out/simcenter-promo.mp4`.
Превью: `npx remotion studio`.

## Пайплайн ассетов

**Скриншоты** — захват через Playwright прямо в рамках текущей сессии (без отдельного
переиспользуемого скрипта — разовая задача):
1. Поднять dev-сервер (`npm run dev`); при необходимости — `npm run staff:reset` и
   `npm run db:seed-simulation` для контента.
2. Войти как evaluator (тестовые учётки из `.env.example`), запустить тестовую live-сессию
   с вымышленным именем участника, получить код доступа.
3. Присоединиться как участник во втором контексте браузера, дойти до `/simulation`.
4. Снять кадры: role-select, evaluator console, simulation (live), results (радар-чарт),
   короткий кадр `/zrd`.
5. Сохранить PNG в `video/simcenter-promo/public/screenshots/`.

**Музыка** — офлайн-скрипт (Node) синтезирует простую амбиент-подложку (синусоиды/пэды) в
WAV, кладётся в `public/audio/bg-music.wav`. Без вопросов лицензирования; звучание
скромное — осознанный компромисс вместо внешнего трека.

## Проверка
- `npx remotion render` завершается без ошибок; `out/simcenter-promo.mp4` существует и
  проигрывается, длительность соответствует 150с.
- В Remotion Studio — нет наложений текста, субтитры читаемы (не быстрее ~15 символов/сек),
  музыка не перекрывает переходы между сценами.
- Итоговый mp4 просматривается целиком перед сдачей.

## Вне рамок (явно не делаем)
- Закадровую озвучку / TTS-голос.
- Лицензированную стороннюю музыку.
- Показ реальных данных/имён сотрудников.
- Изменения в основном приложении (video/ — полностью изолированный проект).
