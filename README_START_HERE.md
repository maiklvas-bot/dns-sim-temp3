# DNS SimCenter — точка входа

Проект ведёт штаб Claude: управляющий (основная сессия) и три профиля исполнителей в `.claude/agents/`. Других ИИ-продуктов в проекте нет.

## Где что лежит

- Правила штаба, роли, маршруты, навыки, «да» владельца: `docs/project/claude-headquarters.md`
- Общие правила репозитория и интерфейса: `AGENTS.md` (подключается из `CLAUDE.md`)
- Краткое описание проекта, границы и проверки: `PROJECT_BRIEF.md`
- Состояние (снимок от 25.09.2026): `docs/project/PROJECT_STATE.md`
- Дорожная карта: `docs/project/ROADMAP.md`
- Журнал: Obsidian, `<OBSIDIAN_VAULT>`, файл `01-projects/simcenter/WORKLOG.md`
- Готовый запрос на продолжение: `prompts/CONTINUE_PROJECT.md`

## Перед любой работой

1. Прочитать `PROJECT_BRIEF.md`, состояние и дорожную карту, `AGENTS.md`.
2. Сделать `git fetch --all --prune`, сверить `origin/main`, текущую ветку, чистоту дерева, PR и CI.
3. Учесть, что в основной копии владельца могут быть незакоммиченные изменения: не перезаписывать и не смешивать их с новой работой.
4. После каждого материального шага записывать его в журнал.

## Основные правила

- существенную правку кода вести в отдельной рабочей копии, один пишущий на копию;
- проверенный коммит сразу уходит в ветку `claude/<тема>-<дата>`; PR, слияние, выкладка, удаление и действия с данными и контентом — только после «да» владельца;
- контент, база и `uploads/` сохраняются;
- CI считается зелёным только для точного текущего коммита.
